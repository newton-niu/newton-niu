## Published Applications

- **MelodyMemo — AI Memory & Music Companion**

  📱 iOS | NLP | Music Recommendation

  An AI-powered music companion that recommends songs based on older adults' personal memories, using emotion extraction and hybrid recommendation methods.

  App Store:

- **ToneScope — Real-Time Sound Spectrum Visualizer**

  📱 iOS | Digital Signal Processing | Audio Visualization

  Developed a multi-resolution FFT system with adaptive tone detection to make sound analysis accessible without manual configuration. ToneScope helps people visualize sound, investigate environmental noise, and identify hard-to-describe frequency patterns.

  App Store:  
  https://apps.apple.com/us/app/tonescope/id6757265327
